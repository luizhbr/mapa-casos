# Mapa de casos — direita e esquerda (últimos dois mandatos)

Site estático em mindmap (vis-network) ligando pessoas e casos, com situação jurídica de cada ligação (condenado, denunciado, indiciado, investigado, citado, arquivado) e fonte.

- `index.html`: site completo, autocontido
- `dados/dados.json`: levantamento do King Bot (casos, pessoas, ligações, fontes)
- `dados/original.json`: dados da primeira versão do mapa
- `merge.py` + `build.sh`: juntam os dados e geram o `index.html`
- `infograficos/`: infográficos de casos e economia

Situação em 17/10/2026.
